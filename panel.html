Acceso

¿Cómo saco la llave? (se hace una sola vez)
  1. Entra a github.com/settings/personal-access-tokens/new.
  2. Nombre: Panel Gatoarisco. Vencimiento: el que prefieras.
  3. En Repository access elige Only select repositories → gatoarisco.
  4. En Permissions → Repository permissions → Contents elige Read and write.
  5. Toca Generate token, cópiala y pégala aquí. Queda guardada solo en este navegador.
